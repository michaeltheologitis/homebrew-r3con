# homebrew-r3trace

A [Homebrew](https://brew.sh) tap for R3Trace, the Mac app of [r3trace](https://github.com/michaeltheologitis/r3trace). It installs the signed, notarized `R3Trace.app` from r3trace's [GitHub Releases](https://github.com/michaeltheologitis/r3trace/releases). Apple silicon only.

```sh
brew install michaeltheologitis/r3trace/r3trace
```

Or tap it, trust the cask, and install it by name:

```sh
brew tap michaeltheologitis/r3trace
brew trust --cask michaeltheologitis/r3trace/r3trace
brew install r3trace
```
