# homebrew-r3con

A [Homebrew](https://brew.sh) tap for R3Con, the Mac app of [r3con](https://github.com/michaeltheologitis/r3con). It installs the signed, notarized `R3Con.app` from r3con's [GitHub Releases](https://github.com/michaeltheologitis/r3con/releases). Apple silicon only.

```sh
brew install michaeltheologitis/r3con/r3con
```

Or tap it, trust the cask, and install it by name:

```sh
brew tap michaeltheologitis/r3con
brew trust --cask michaeltheologitis/r3con/r3con
brew install r3con
```
